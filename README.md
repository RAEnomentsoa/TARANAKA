Rôle : Tu es un UI/UX Designer et développeur mobile senior expert dans la création d'applications de santé inclusives et accessibles.



Instructions :

Conçois l'écran d'accueil mobile pour une application de santé communautaire appelée "TARANAKA", selon les spécifications ci-dessous. Le design doit s'inspirer de la charte graphique et du thème UNICEF (utilises le thème disponible dans le dossier `themes`). Il doit être épuré, très accessible, avec de grands boutons (minimum 44px de zone tactile) et une typographie claire.



1. Barre d'en-tête (AppBar) :

- Afficher le nom de l'application : "TARANAKA" en gras.

- À droite de l'AppBar, ajouter deux icônes de drapeaux interactives pour changer la langue :

  * Drapeau de Madagascar (Malagasy - langue par défaut)

  * Drapeau de la France (Français)

- La sélection d'un drapeau doit changer dynamiquement tous les titres de la page.



2. Grille de contenu (4 Grandes Tuiles en disposition 2x2) :



- Tuile 1 (Haut - Gauche) :

  * Icône : Cycle menstruel

  * Titre Malagasy : "Ny fadimbolanako"

  * Titre Français : "Mes règles"



- Tuile 2 (Haut - Droite) :

  * Icône : Femme enceinte

  * Titre Malagasy : "Ny vohokako"

  * Titre Français : "Ma grossesse"



- Tuile 3 (Bas - Gauche) :

  * Icône : Mère tenant un bébé dans ses bras

  * Titre Malagasy : "Ny zanako"

  * Titre Français : "Mon enfant"



- Tuile 4 (Bas - Droite) :

  * Icône : Tensiomètre de docteur / Matériel médical

  * Titre Malagasy : "Tsy fahampian-tsakafo sy fandraisana an-tanana"

  * Titre Français : "Malnutrition et prise en charge"



3. Ergonomie & UI :

- Appliquer le thème visuel UNICEF situé dans le dossier `themes` (couleurs, typographies et styles).

- Les 4 tuiles doivent avoir la même taille, être clairement séparées avec de la marge, des coins arrondis et une légère ombre.

- Les icônes doivent être bien visibles au-dessus du texte correspondant.

- Prévoir un état réactif pour la gestion du changement de langue (`mg` par défaut, `fr` optionnel).
